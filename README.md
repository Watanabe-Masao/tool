# 歩留まり計算ツール（リファクタリング版）

食品加工業向けの歩留まり率・原価・売価・値入率を計算するWebアプリケーションです。

## 🎯 リファクタリングの概要

このプロジェクトは、コード品質向上のために以下のリファクタリングを実施しました：

### 主な改善点

1. **モジュール化による責務の分離**
   - 計算ロジック、表示処理、入力処理、状態管理を独立したモジュールに分割
   - 各モジュールが単一責任の原則に従うよう設計

2. **定数の抽出**
   - マジックナンバー（100, 1000など）を定数化
   - UI要素IDを一箇所で管理し、タイポを防止

3. **状態管理の一元化**
   - グローバル変数をStateクラスで管理
   - 状態の変更を追跡しやすく

4. **重複コードの削減**
   - 定額モードと計量モードの共通処理を統合
   - 再利用可能な関数の作成

5. **コード量の削減**
   - main.jsを241行から152行に短縮（37%削減）
   - より読みやすく保守しやすいコードへ

## 🔧 モジュール詳細

### constants.js
- アプリケーション全体で使用する定数を定義
- UI要素ID、計算定数、ラベルなどを一箇所で管理

### state.js
- アプリケーションの状態を管理するStateクラス
- 計算結果のスナップショット、商品化シミュレーションデータを保持

### calculation.js
- 純粋な計算関数のみを含む（副作用なし）
- 歩留まり率、値入率、粗利率などの計算

### calculator-fixed.js / calculator-weight.js
- 各モードの計算ロジックを分離
- 入力値の取得、バリデーション、計算を一貫して処理

### input-handler.js
- 入力フィールドの管理
- イベントリスナーのバインド
- ラジオボタンの切り替え処理

### display.js
- 計算結果の表示処理
- DOM要素への値の反映
- 表示/非表示の切り替え

### product-simulator.js
- 商品化シミュレーションの計算
- 値引き後粗利率の計算

### dom-utils.js
- DOM操作のユーティリティ関数
- querySelector、イベントバインド、フォーマット関数など

### main.js
- アプリケーションのエントリーポイント
- 各モジュールを統合し、初期化処理を実行
- 152行のシンプルなコード

## 🚀 使い方

1. ブラウザで `index.html` を開く
2. 計算モードを選択（定額売価→計量加工 / 計量売価→計量加工）
3. 必要な項目を入力
4. 自動的に計算結果が表示されます

## ✨ 機能

- **2つの計算モード**
  - 定額売価→計量加工
  - 計量売価→計量加工

- **歩留まり率の計算方法**
  - 重量から自動計算
  - 歩留まり率を直接入力

- **計算結果**
  - 加工前後の100gあたり原価・売価
  - 値入率・粗利率
  - 仕上がり売価と差額

- **商品化シミュレーション**
  - 想定商品化原価・売価・値入率の計算
  - 消耗品費の考慮

- **値引きシミュレーション**
  - 値引き後の粗利率を計算
  - スライダーで直感的に操作
