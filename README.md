# 歩留まり計算ツール

食品加工業で使う **歩留まり率・原価・売価・値入率** を計算できるウェブアプリです。PWA 対応・オフライン動作・履歴保存に対応しています。

> この README は「入口（ナビゲーション）」に特化しています。利用方法・開発方法・計算仕様は下記の個別ドキュメントをご覧ください。

- 開発者ガイド（実装/構成）: [`docs/DEVELOPER_GUIDE.md`](docs/DEVELOPER_GUIDE.md)
- 技術仕様（数式/ロジック）: [`docs/TECHNICAL_SPEC.md`](docs/TECHNICAL_SPEC.md)

## 特徴（概要）
- **PWA/完全オフライン**：ホーム画面追加、スプラッシュ表示、キャッシュ戦略により通信なしで利用可能
- **履歴管理（IndexedDB）**：計算結果を保存・検索・編集・削除、JSON で入出力
- **ステップ式UI**：モード切替・段階的入力で迷わず計算
- **値引き/粗利シミュレーション**：販売戦略に必要な逆算が可能
