# 歩留まり計算ツール

食品加工業向けの歩留まり率・原価・売価・値入率を計算するWebアプリケーションです。

## 🎯 主な機能

### ステップ式の段階的計算
各計算モードで、ステップごとに入力と結果を確認しながら進められます：
- **Step 1**: 箱の基本情報 → 加工前の原価・売価・値入率を表示
- **Step 2**: 重量または歩留まり率の入力 → 歩留まり率を表示
- **Step 3**: 加工後の売価設定 → 加工後の原価・売価・値入率を表示

### 逆算シミュレーション機能 🔄
目標値入率から、必要な値を逆算できます：
- **1パックに入れる予定重量（g）**
- **加工後設定売価（100gあたり）**
- **1個あたりの原価（円）**
- **加工後重量（g）/ 歩留まり率（%）** - モードに応じて自動切替
- **値引率（%）** - 目標粗利率から逆算

### エラーハンドリング
計算不可能な場合、具体的なエラーメッセージを表示：
- 有効範囲の提示（例：「目標値入率は25.00%以下で設定してください」）
- 必須入力の通知
- 制約条件の説明

### モバイル対応
- タップしやすい大きなボタン
- クリック可能な要素の明確な視覚表示
- アニメーション効果でインタラクティブな操作感

## 🔧 モジュール詳細

### constants.js
- アプリケーション全体で使用する定数を定義
- UI要素ID、計算定数、ラベルなどを一箇所で管理

### state.js
- アプリケーションの状態を管理するStateクラス
- 計算結果のスナップショット、商品化シミュレーションデータを保持

### calculation.js
- 純粋な計算関数のみを含む（副作用なし）
- 歩留まり率、値入率、粗利率などの計算

### calculator-fixed.js / calculator-weight.js
- 各モードの計算ロジックを分離
- 入力値の取得、バリデーション、計算を一貫して処理

### input-handler.js
- 入力フィールドの管理
- イベントリスナーのバインド
- ラジオボタンの切り替え処理

### display.js
- 計算結果の表示処理
- DOM要素への値の反映
- 表示/非表示の切り替え
- 逆算シミュレーション結果とエラーメッセージの表示

### product-simulator.js
- 商品化シミュレーションの計算
- 値引後最終粗利率の計算
- 逆算シミュレーション用の計算関数群
  - 重量、売価、消耗品費、歩留まり率、値引率の逆算

### dom-utils.js
- DOM操作のユーティリティ関数
- querySelector、イベントバインド、フォーマット関数など

### main.js
- アプリケーションのエントリーポイント
- 各モジュールを統合し、初期化処理を実行
- ステップ式表示と逆算シミュレーションのロジックを含む

## 🚀 使い方

### 基本的な流れ

1. **モード選択**
   - 「定額売価→計量加工」または「計量売価→計量加工」を選択

2. **ステップ1: 箱の基本情報**
   - 1箱あたりの原価・売価・重量を入力
   - 加工前の100gあたり原価・売価・値入率が表示されます

3. **ステップ2: 歩留まり率の設定**
   - 「重量から計算」: 加工前後の重量を入力して自動計算
   - 「歩留まり率直接入力」: 歩留まり率を直接入力

4. **ステップ3: 加工後の売価設定**
   - 加工後の100gあたり売価を入力
   - 加工後の原価・売価・値入率が表示されます

5. **ステップ4: 商品化シミュレーション**
   - 1パックの重量と消耗品費を入力
   - 商品化後の原価・売価・値入率を確認

6. **ステップ5: 値引きシミュレーション**
   - 値引率をスライダーで調整
   - 値引き後の粗利率を確認
   - 値引後最終粗利率をクリック → 逆算シミュレーションを開く

### 逆算シミュレーションの使い方

1. **値引後最終粗利率をクリック/タップ**
   - ステップ5の「値引後最終粗利率」カードをクリック

2. **計算したい項目を選択**
   - ラジオボタンで逆算したい変数を選択

3. **目標値入率を入力**
   - 達成したい目標値を入力

4. **結果を確認**
   - 計算結果または具体的なエラーメッセージが表示されます

## ✨ 詳細機能

### 計算モード
- **定額売価→計量加工**: 箱単位で仕入れ、100g単位で販売
- **計量売価→計量加工**: 100g単位で仕入れ、100g単位で販売

### 歩留まり率の計算
- **重量から計算**: 加工前後の実測重量から自動計算
- **歩留まり率直接入力**: 既知の歩留まり率を入力

### 表示される情報
- 加工前後の100gあたり原価・売価
- 値入率・粗利率
- 仕上がり売価と差額（定額モードのみ）
- 商品化シミュレーション結果
- 値引後最終粗利率

## 🎓 設計のポイント

### アーキテクチャ
- **モジュール化**: 責務ごとにファイルを分割（10ファイル）
- **状態管理**: Stateクラスで一元管理
- **定数化**: UI要素IDや計算定数を一箇所で管理
- **純粋関数**: 副作用のない計算関数

### ユーザーエクスペリエンス
- **段階的表示**: ステップごとに進行を確認
- **即座のフィードバック**: 入力時にリアルタイム計算
- **エラーガイド**: 具体的なエラーメッセージで問題解決を支援
- **逆算機能**: 目標から必要条件を導出

### コード品質
- **DRY原則**: 重複コードの排除
- **単一責任**: 各モジュールが明確な役割を持つ
- **拡張性**: 新機能の追加が容易な設計
