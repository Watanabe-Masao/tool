## 歩留まり統計モードとは

### 目的

複数サンプルの加工前後の重量データから**歩留まり率を統計的に分析**し、信頼性の高い代表値を導出します。

### 用途

- ✅ 新商品の歩留まり率を決定する際の根拠データ収集
- ✅ 既存商品の歩留まり率の見直し
- ✅ サンプル数が十分かどうかの判断
- ✅ データのばらつきや外れ値の確認

### なぜ統計分析が必要？

**単一サンプルの問題点**:
- 1個だけのサンプルでは信頼性が低い
- たまたま良い個体、悪い個体に当たる可能性がある

**統計分析のメリット**:
- 複数サンプルから平均的な値を算出
- データのばらつきを定量的に評価
- 外れ値を検出して除外できる
- 必要なサンプル数を科学的に判断できる

## データ入力

### Excel風テーブル

スプレッドシート風のUIで直感的にデータを入力できます。

### 入力方法

1. **加工前重量（g）** 欄をクリックして数値を入力
2. **Tab**キーまたは**Enter**キーで次の欄（加工後重量）に移動
3. **加工後重量（g）** を入力
4. **Enter**キーで次の行に移動
5. 最終行に入力すると、自動的に新しい行が追加されます

### データ要件

- **最低データ数**: 2件以上
- **有効なデータ**: 加工前重量と加工後重量の**両方**が入力されたデータのみ統計分析に使用

### 歩留まり率の自動計算

各行の歩留まり率は自動的に計算されます：

```
歩留まり率 = (加工後重量 / 加工前重量) × 100
```

**例**:
- 加工前重量: 1,000g
- 加工後重量: 850g
- 歩留まり率: 85.0%

## マトリックス評価

### 概要

データの品質を総合的に評価し、4段階で表示します。

### 評価基準

#### 🌟 優秀（緑）

**条件**:
- 変動係数（CV） ≤ 3%
- サンプル数 ≥ 必要サンプル数

**意味**: データは非常に安定しており、サンプル数も十分です。

#### ✓ 良好（緑）

**条件**:
- 変動係数（CV） ≤ 5%

**意味**: データは安定しています。

#### ⚡ 要注意（黄）

**条件**:
- 変動係数（CV） > 5%

**意味**: データにやや大きなばらつきがあります。

#### ⚠️ 改善推奨（黄/赤）

**条件**: その他

**意味**: データのばらつきが大きい、またはサンプル数が不足しています。

### 改善アクション

評価に応じて、具体的な改善アクションが表示されます：

- **サンプル数追加**: 必要サンプル数に達していない場合
- **外れ値除外**: 外れ値が検出された場合
- **データ収集条件の見直し**: ばらつきが大きい場合

## 基本統計量

### データ数

有効なデータの件数（両方の重量が入力されたデータのみカウント）

### 最大値・最小値・範囲

- **最大値**: データセット内の最大値
- **最小値**: データセット内の最小値
- **範囲（レンジ）**: 最大値 - 最小値

**意味**: データのばらつきの広さを示します。

### 平均値（算術平均）

**計算式**:
```
x̄ = (x₁ + x₂ + ... + xₙ) / n
```

**意味**:
- 全データの合計をデータ数で割った値
- データの中心的な傾向を表す

**例**:
- データ: 80%, 85%, 90%
- 平均値: (80 + 85 + 90) / 3 = 85.0%

### 中央値（メディアン）

**計算方法**:
1. データを昇順に並べる
2. nが奇数: 中央の値
3. nが偶数: 中央2つの値の平均

**意味**:
- **外れ値の影響を受けにくい**
- 歪んだ分布に適している

**例**:
- データ: 50%, 80%, 85%, 90%, 95%
- 中央値: 85%（真ん中の値）

### 標準偏差（σ）

**計算式**:
```
σ = √(Σ(xᵢ - x̄)² / n)
```

**意味**:
- データのばらつき（散らばり具合）を示す
- 値が大きいほどデータが平均値から離れている

**例**:
- 標準偏差が小さい → データが平均値に集中
- 標準偏差が大きい → データがばらついている

### 変動係数（CV）

**計算式**:
```
CV = (σ / x̄) × 100 (%)
```

**意味**:
- 標準偏差を平均値で割った値
- 異なる単位や規模のデータのばらつきを比較できる

**判定基準**:
- **10%以下**: ばらつきが小さい ✅
- **10-20%**: 中程度のばらつき ⚠️
- **20%以上**: ばらつきが大きい ❌

**例**:
- 平均値: 85%、標準偏差: 4.25%
- CV = (4.25 / 85) × 100 = 5.0%
- 判定: ばらつきが小さい ✅

## 四分位数と分布

### 第1四分位数（Q1）

- データを昇順に並べたとき、**25%の位置**にある値
- 下位25%のデータの境界

### 第3四分位数（Q3）

- データを昇順に並べたとき、**75%の位置**にある値
- 上位25%のデータの境界

### 四分位範囲（IQR）

**計算式**:
```
IQR = Q3 - Q1
```

**意味**:
- 中央50%のデータの広がりを示す
- 外れ値の影響を受けにくい指標

### 歪度（Skewness）

**計算式**:
```
Skewness = Σ((xᵢ - x̄) / σ)³ / n
```

**意味**: 分布の左右対称性を示す

**判定基準**:
- **0に近い**: 左右対称（正規分布に近い）
- **正の値**: 右に裾が長い（高い値の外れ値がある）
- **負の値**: 左に裾が長い（低い値の外れ値がある）

### 尖度（Kurtosis）

**計算式**:
```
Kurtosis = Σ((xᵢ - x̄) / σ)⁴ / n - 3
```

**意味**: 分布の尖り具合を示す

**判定基準**:
- **0**: 正規分布と同じ尖り具合
- **正の値**: 正規分布より尖っている（外れ値が多い）
- **負の値**: なだらか（データが均一）

## 信頼区間分析

### 正規分布におけるσ範囲

データが正規分布に従うと仮定した場合の信頼区間です。

### σ1範囲（68.3%）

**範囲**:
```
[x̄ - σ, x̄ + σ]
```

**意味**: 約**68.3%のデータ**がこの範囲に含まれる

**例**:
- 平均値: 85%、標準偏差: 5%
- σ1範囲: [80%, 90%]

### σ2範囲（95.4%）

**範囲**:
```
[x̄ - 2σ, x̄ + 2σ]
```

**意味**: 約**95.4%のデータ**がこの範囲に含まれる

**例**:
- 平均値: 85%、標準偏差: 5%
- σ2範囲: [75%, 95%]

### σ3範囲（99.7%）

**範囲**:
```
[x̄ - 3σ, x̄ + 3σ]
```

**意味**:
- 約**99.7%のデータ**がこの範囲に含まれる
- この範囲外はほぼ外れ値と見なせる

**例**:
- 平均値: 85%、標準偏差: 5%
- σ3範囲: [70%, 100%]

## サンプルサイズの妥当性判断

### 目的

統計的に十分なサンプル数を確保できているかを判定します。

### 必要サンプルサイズの計算

**計算式**:
```
n = (Z × σ / E)²
```

- **Z**: 信頼水準に対応するZ値
- **σ**: 標準偏差
- **E**: 許容誤差

### 信頼水準とZ値の対応

- **90%**: Z = 1.645
- **95%**: Z = 1.960（最も一般的） ⭐
- **99%**: Z = 2.576

**意味**: 推定値が正しい範囲に含まれる確率

### 許容誤差（E）

**意味**: 推定値と真の値の間で許容できる誤差の大きさ

**例**:
- 許容誤差: 2.0%
- 意味: 真の値±2.0%の範囲で推定したい

**注意**:
- 小さいほど精度が高くなるが、より多くのサンプルが必要

### 判定基準

- **実際のサンプル数 ≥ 必要サンプル数**: ✅ 妥当
- **実際のサンプル数 < 必要サンプル数**: ❌ 不足

### 表示内容

- 現在のサンプル数
- 必要サンプル数（小数点以下切り上げ）
- 充足率（プログレスバー表示）
- 判定結果（妥当/不足）
- 具体的な説明とアクション

### カラーコーディング

- **緑**: 充足率 ≥ 100%（十分なサンプル数）
- **黄**: 充足率 80-99%（やや不足）
- **赤**: 充足率 < 80%（大幅に不足）

## 外れ値検出と削除

### IQR法による外れ値検出

**計算式**:
```
外れ値 = データ < Q1 - 1.5×IQR または データ > Q3 + 1.5×IQR
```

**正常範囲**:
```
[Q1 - 1.5×IQR, Q3 + 1.5×IQR]
```

**意味**:
- この範囲外のデータは「外れ値」と判定される
- IQR法は一般的に使用される統計的手法

### 表示内容

- 外れ値の件数
- 正常範囲の値
- 外れ値のリスト（行番号と値）

### 外れ値の操作

1. **選択**: 外れ値をチェックボックスで選択
2. **すべて選択**: ワンクリックで全外れ値を選択
3. **すべて解除**: 選択を解除
4. **削除**: 「外れ値を含む行をテーブルから削除」ボタンをクリック

**削除後**:
- 統計が自動再計算される
- 外れ値を除外した結果が表示される

### 視覚化

- テーブル上で外れ値を含む行を**赤系の背景色でハイライト**表示
- 行番号を強調表示

## 推奨代表値

### 目的

平均値と中央値のどちらを採用すべきかを自動判定します。

### 自動判定ロジック

**基準**: 歪度の絶対値

**判定ルール**:
```
|歪度| ≤ 0.5 → 平均値を推奨
|歪度| > 0.5 → 中央値を推奨
```

### 理由

- **平均値**: 分布が対称的な場合に適している
- **中央値**: 分布が歪んでいる場合や外れ値がある場合に適している

### 表示内容

- 推奨される代表値（平均値 or 中央値）
- 判定理由の説明
- 実際の値

**例**:
```
🌟 推奨代表値: 中央値 (85.2%)
理由: 歪度の絶対値が0.5を超えているため、中央値が適しています。
```

## グラフ表示

### 対応グラフ種類

#### 1. 箱ひげ図（Box Plot）

**特徴**:
- データの分布を5つの数値で要約
- 最小値、Q1、中央値、Q3、最大値
- 外れ値を点で表示

**用途**: データの分布の概要を把握

#### 2. ヒストグラム（Histogram）

**特徴**:
- データの度数分布を棒グラフで表示
- ビンの数は自動計算（Sturgesの公式）

**用途**: データの偏りを視覚的に確認

#### 3. 散布図（Scatter Plot）

**特徴**:
- 各データ点をプロット
- 加工前重量と歩留まり率の関係を表示

**用途**: データの傾向やパターンを把握

#### 4. 正規分布曲線（Normal Distribution）

**特徴**:
- 理論的な正規分布曲線をヒストグラムに重ねて表示

**用途**: 実際のデータが正規分布に従うかを確認

#### 5. Q-Qプロット（Q-Q Plot）

**特徴**:
- 実際のデータと理論的な正規分布を比較
- データが正規分布に従う場合、点は直線上に並ぶ

**用途**: 正規性の検定

### 分析対象の切り替え

以下の3つの分析対象を切り替えできます：

- **歩留まり率**: 最も一般的な分析対象
- **加工前重量**: サンプルの元の重量の分布を確認
- **加工後重量**: 加工後の重量の分布を確認

### 使い方

1. 「**表示する統計**」ドロップダウンで対象を選択
2. 「**グラフ種類**」ドロップダウンでグラフタイプを選択
3. グラフが自動的に更新される

## 実践的な使い方

### ユースケース1: 新商品の歩留まり率を決定

#### 状況

新しいトマト商品を開発中。適切な歩留まり率を設定したい。

#### 手順

1. **サンプル収集**: 10個のトマトを用意
2. **データ入力**: 各トマトの加工前後の重量を測定して入力
3. **統計分析**: 平均値、中央値、標準偏差を確認
4. **外れ値除外**: IQR法で外れ値を検出して除外
5. **推奨代表値を確認**: 歪度に基づいて平均値 or 中央値を選択
6. **サンプルサイズ検証**: 必要サンプル数を確認
7. **追加サンプル**: 不足していれば追加収集

#### 結果

- 推奨代表値: **85.2%**（中央値）
- サンプル数: **10件**（必要サンプル数: 8件） ✅
- 判定: 妥当なサンプル数

### ユースケース2: 既存商品の歩留まり率を見直し

#### 状況

現在80%で設定している歩留まり率が適切か検証したい。

#### 手順

1. **データ収集**: 複数サンプルを測定
2. **統計分析**: 現在の設定値（80%）が信頼区間内にあるか確認
3. **変動係数確認**: CVが大きい場合は加工条件を見直し
4. **推奨代表値を確認**: より適切な値を設定

#### 結果

- 平均値: **82.5%**
- σ2範囲: [77.0%, 88.0%]
- 現在の設定値（80%）は範囲内 ✅
- ただし、平均値に近い**82.5%**への変更を検討

### ユースケース3: 外れ値の原因究明

#### 状況

10サンプル中、1サンプルだけ歩留まり率が極端に低い。

#### 手順

1. **外れ値検出**: IQR法で外れ値を自動検出
2. **原因究明**:
   - サンプルの品質が悪かった？
   - 測定ミス？
   - 加工ミス？
3. **除外判断**: 原因が明確なら除外
4. **再計算**: 外れ値を除外して統計を再計算

#### 結果

- 外れ値除外前: 平均値 **78.5%**
- 外れ値除外後: 平均値 **82.0%**
- より信頼性の高い値を得られた ✅

## ヒントとベストプラクティス

### データ収集のコツ

1. **サンプル数**: 最低10件以上を推奨
2. **サンプル選定**: ランダムに選ぶ（良いものばかり選ばない）
3. **測定精度**: デジタル秤で正確に測定
4. **記録**: 測定日時、条件をメモしておく

### 分析のコツ

1. **複数の指標を確認**: 平均値だけでなく、中央値、CV、外れ値も確認
2. **グラフを活用**: ヒストグラムや箱ひげ図で視覚的に把握
3. **サンプル数の確認**: 統計的に十分なサンプル数を確保
4. **外れ値の扱い**: 原因を究明してから除外

### よくある間違い

❌ **サンプル数が少なすぎる**
- 2〜3件では信頼性が低い
- 最低10件以上を推奨

❌ **外れ値を無視する**
- 外れ値は重要な情報
- 原因を究明することが大切

❌ **平均値だけを見る**
- 中央値、標準偏差、CVも確認
- 歪んだ分布では中央値が適切

## トラブルシューティング

### Q: サンプル数が不足していると表示される

**A**: 必要サンプル数に達していません。

**対策**:
- 追加でサンプルを収集
- 許容誤差を大きくする（精度は下がる）
- 信頼水準を下げる（推奨しない）

### Q: 変動係数（CV）が大きい

**A**: データのばらつきが大きいです。

**対策**:
- 加工条件を統一する
- サンプルの品質を揃える
- 測定方法を見直す
- 外れ値を除外する

### Q: 外れ値が多い

**A**: データに異常値が多く含まれています。

**対策**:
- 測定ミスがないか確認
- 加工条件を統一する
- サンプルの選定を見直す
