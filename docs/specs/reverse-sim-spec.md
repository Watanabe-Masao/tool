# 逆算シミュレーション仕様（値引き後粗利率版）

本ドキュメントは"逆算シミュレーション"で **値引き後粗利率** を正しく配置した式で 1 個あたりの原価（円）を求めるための仕様をまとめたものです。

## 記号
- **bp**: 値引き前単価（円/個）
- **dc**: 値引き額（円/個）
- **ap**: 値引き後単価 (= bp - dc)（円/個）
- **yr**: 値引き後粗利率（%）※小数で計算する場合は `yr_dec = yr / 100`
- **am**: 加工後重量（g/個）
- **bm**: 加工前重量（g/個）
- **bc**: 原価（円/g）※重量単価ベースの原価を扱う場合

## 目的
**値引き後粗利率（yr）を基準**に、1 個あたりの原価（円/個）= `ac` を求める。

## 基本式
粗利率の定義：

```
粗利率 = 粗利 / 売価 = (売価 - 原価) / 売価
```

値引き後粗利率 `yr` を用いるので、売価は **ap**（値引き後単価）。よって：

```
( ap - ac ) / ap = yr_dec   ⇒   ac = ap * (1 - yr_dec) = ap * (1 - yr/100)
```

> つまり **1 個あたりの原価（円）= 値引き後単価 × (1 - 値引き後粗利率)** となります。

## 重量ベース原価との整合
重量ベースで原価を入れる UI の場合、1 個あたりの原価は：

```
ac_weight = am * bc
```

もし UI 上で `ac` を重量から逆算する場合は、

```
ac = ac_weight = am * bc
yr_dec = 1 - (ac / ap)   （= 1 - (am * bc) / ap）
```

## 必須入力とバリデーション
- **ap** は `bp - dc` で求める（どちらかが未入力なら計算不可）。
- **yr** は 0〜100 の範囲（%）。
- **am** は重量ベース原価を使う（= `bc` を使う）場合に **必須**。
- **am** が未入力で重量ベース原価計算を選んでいる場合は、エラー：
  - `加工後重量を入力してください`

## 代表例
- 例: `bp=200`, `dc=20` → `ap=180`、`yr=35%` のとき：
  - `ac = 180 * (1 - 0.35) = 117（円/個）`
- 例: 重量ベース `am=150g`、`bc=0.6 円/g` のとき：
  - `ac = 150 * 0.6 = 90（円/個）`、`yr = 1 - 90/180 = 50%`

## 実装メモ（フロント）
- `state` に `yr`（値引き後粗利率）を **必ず保持**し、`displayResults()` で `{ ac, ap, bm, am, bp, bc, yr }` を返す。
- バリデーション：
  - `yr`（%）の範囲チェック（0〜100）。
  - 重量原価モード時は `am` を必須。
- エラーメッセージは日本語で統一し、未入力理由が分かる文言にする。
