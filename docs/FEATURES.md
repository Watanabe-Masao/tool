## 計算機能

### 計算モード

#### 1. 定額売価→計量加工
**用途**: 箱単位で仕入れ、100g単位で販売する場合

**計算フロー**:
1. 1個あたりの原価・売価・重量を入力
2. 加工前の100gあたり原価・売価・値入率を計算
3. 加工後重量から歩留まり率を計算
4. 加工後の100gあたり原価・売価・値入率を計算

**表示項目**:
- 加工前100g単価、売価、値入率
- 歩留まり率
- 加工後100g原価、売価、値入率
- 仕上がり売価と差額

#### 2. 計量売価→計量加工
**用途**: 100g単位で仕入れ、100g単位で販売する場合

**計算フロー**:
1. 1箱あたりの原価・売価・重量を入力
2. 加工前の100gあたり原価・売価・値入率を計算
3. サンプル重量から歩留まり率を計算
4. 加工後の100gあたり原価・売価・値入率を計算

### 歩留まり率の計算方法

#### 重量から計算
- 加工前重量と加工後重量を入力
- 歩留まり率 = (加工後重量 / 加工前重量) × 100

#### 歩留まり率直接入力
- 既知の歩留まり率を直接入力
- 経験値やデータベースから参照する場合に使用

### シミュレーション機能

#### 商品化シミュレーション
**目的**: パック化後の実売価格を計算

**入力項目**:
- 1パックに入れる予定重量（g）
- 消耗品費（円）

**出力項目**:
- パック原価
- パック売価
- パック値入率

**計算式**:
```
パック原価 = 加工後100g原価 × (重量 / 100) + 消耗品費
パック売価 = 加工後100g売価 × (重量 / 100)
パック値入率 = ((パック売価 - パック原価) / パック売価) × 100
```

#### 値引きシミュレーション
**目的**: 値引後の粗利率を確認

**入力項目**:
- 値引率（%）：スライダーで0〜50%まで調整可能

**出力項目**:
- 値引後最終粗利率

**計算式**:
```
値引後粗利率 = 値入率 / (1 - 値引率/100)
```

#### 逆算シミュレーション
**目的**: 目標値入率から必要な値を逆算

**操作方法**:
1. 「値引後最終粗利率」カードをクリック/タップ
2. 逆算したい項目を選択
3. 目標値入率を入力

**逆算可能な項目**:

1. **重量（g）**
   - 目標値入率を達成するための必要重量

2. **100gあたり売価（円）**
   - 目標値入率を達成するための必要売価

3. **原価（円）**
   - 定額モード: 1個あたりの原価
   - 計量モード: 1箱あたりの原価

4. **歩留まり率（%）/ 加工後重量（g）**
   - 入力方法に応じて自動切替
   - 重量から計算: 加工後重量
   - 直接入力: 歩留まり率

5. **値引率（%）**
   - 目標粗利率を達成するための必要値引率

**エラーハンドリング**:
- 計算不可能な場合、具体的なエラーメッセージを表示
- 有効範囲を提示（例: 「目標値入率は25.00%以下で設定してください」）

## データ管理機能

### 保存機能

#### カテゴリー優先の保存フロー
**手順**:
1. 計算完了後、「💾 この計算を保存」をクリック
2. **カテゴリーを選択**（野菜/果実）
3. **商品名を入力**
   - カテゴリーに応じた商品名候補が表示される
   - 既存の商品名から選択または新規入力
4. 保存ボタンをクリック

**カテゴリー別フィルタリング**:
- カテゴリーを選択すると、そのカテゴリーに属する商品名のみが表示
- 例: 「野菜」を選択 → データベース内の野菜カテゴリーの商品名のみ表示

**保存されるデータ**:
- 商品名
- カテゴリー
- 計算モード（定額/計量）
- 入力値（原価、売価、重量、歩留まり率など）
- 計算結果（値入率、粗利率など）
- 商品化データ（パック重量、消耗品費など）
- 値引後最終粗利率
- タイムスタンプ

### 履歴管理

#### 履歴表示
**表示項目**（2行レイアウト）:

**1行目**:
- 1個（箱）あたりの原価
- 1個（箱）あたりの売価
- 値入率

**2行目**:
- 歩留まり率
- 最終粗利率（値引後）

**その他の情報**:
- 商品名
- カテゴリーアイコン（🥬 野菜 / 🍎 果実）
- 計算モード（定額売価 / 計量売価）
- 保存日時

#### スワイプUI
**機能**: 同一商品名の履歴を横スワイプで切り替え

**特徴**:
- タッチとマウスドラッグの両方に対応
- 20%以上スワイプで切り替え
- インジケーターで現在位置を表示
- 複数履歴がある場合は「○件の履歴」と表示

**グループ化ロジック**:
- 商品名とカテゴリーの組み合わせでグループ化
- 同じ商品名でもカテゴリーが異なる場合は別グループ

#### 操作機能

**読込** 📂:
- 保存した計算を復元
- モードを自動切替
- 入力方法を自動設定
- 全入力値を復元
- 計算を自動実行

**編集** ✏️:
- 商品名を変更
- カテゴリーを変更

**削除** 🗑️:
- 確認ダイアログ表示後に削除

**検索**:
- 商品名でリアルタイム絞り込み
- 部分一致検索

### データ移行

#### エクスポート
**形式**: JSON
**含まれる情報**:
- 全履歴データ
- メタデータ（エクスポート日時、件数）

**用途**:
- バックアップ
- 別端末への移行
- データ分析

#### インポート
**機能**:
- JSONファイルからデータを復元
- 既存データとマージ
- 重複チェック（タイムスタンプで判定）

## PWA機能

### オフライン対応

#### Service Worker
**キャッシュ戦略**: Network First with Cache Fallback

**動作**:
1. まずネットワークから最新版を取得
2. ネットワークが利用できない場合、キャッシュから提供
3. 取得した最新版をキャッシュに保存

**キャッシュ対象**:
- HTML、CSS、JavaScript
- アプリアイコン
- manifest.json

**バージョン管理**:
```javascript
CACHE_VERSION = 3
CACHE_BUILD = 'YYYYMMDD-XXX'
CACHE_NAME = 'yield-calculator-v3-20250125-002'
```

#### 自動更新通知
**仕組み**:
1. 1時間ごとに新バージョンをチェック
2. 新バージョンが検出されたら通知を表示
3. ユーザーが「更新」ボタンをクリック
4. 新バージョンを即座に適用

**通知UI**:
```
🔄 新しいバージョンが利用可能です [更新] [✕]
```

### ホーム画面に追加

#### manifest.json
**設定内容**:
- アプリ名: 「歩留まり計算ツール」
- 短縮名: 「歩留まり計算」
- 表示モード: standalone（フルスクリーン）
- 向き: portrait-primary（縦向き）
- テーマカラー: #5c6bc0
- アイコン: 72px〜512px（8サイズ）

#### インストール体験
**Android（Chrome）**:
1. 「ホーム画面に追加」プロンプトが自動表示
2. または メニュー → 「ホーム画面に追加」

**iOS（Safari）**:
1. 共有ボタン → 「ホーム画面に追加」

**PC（Chrome/Edge）**:
1. アドレスバーのインストールアイコンをクリック

### キャッシュ最適化

**メタタグ**:
```html
<meta http-equiv="Cache-Control" content="no-cache, no-store, must-revalidate" />
<meta http-equiv="Pragma" content="no-cache" />
<meta http-equiv="Expires" content="0" />
```

**効果**:
- ブラウザキャッシュを無効化
- 常に最新版を取得
- PWAキャッシュは Service Worker で管理

## データ構造

### IndexedDB スキーマ

**データベース名**: YieldCalculatorDB
**ストア名**: calculations
**キー**: 自動インクリメント ID

**インデックス**:
- timestamp: 保存日時
- name: 商品名
- mode: 計算モード
- category: カテゴリー

**データ構造**:
```javascript
{
  id: number,                 // 自動インクリメント
  name: string,               // 商品名
  category: string,           // カテゴリー（vegetable/fruit）
  mode: string,               // 計算モード（fixed/weight）
  input: {                    // 入力値
    mode: string,
    yieldMethod: string,      // 歩留まり計算方法
    unitCost: number,         // 1個あたり原価（定額モード）
    unitPrice: number,        // 1個あたり売価（定額モード）
    boxCost: number,          // 1箱あたり原価（計量モード）
    boxPrice: number,         // 1箱あたり売価（計量モード）
    beforeWeight: number,     // 加工前重量
    afterWeight: number,      // 加工後重量
    yieldRate: number,        // 歩留まり率
    afterPrice100: number,    // 加工後100g売価
    expWeight: number,        // パック重量
    consumable: number        // 消耗品費
  },
  result: {                   // 計算結果
    yr: number,               // 歩留まり率
    bc: number,               // 加工前100g原価
    bp: number,               // 加工前100g売価
    ac: number,               // 加工後100g原価
    ap: number,               // 加工後100g売価
    bm: number,               // 加工前値入率
    am: number,               // 加工後値入率
    yieldRate: number,        // 歩留まり率（スナップショット）
    afterMarkup: number,      // 加工後値入率（別名）
    discountGross: number     // 値引後最終粗利率
  },
  product: {                  // 商品化データ
    price: number,            // パック売価
    markup: number,           // パック値入率
    cost: number              // パック原価
  },
  timestamp: number,          // 保存日時（ミリ秒）
  createdAt: string,          // 作成日時（ISO文字列）
  updatedAt: string           // 更新日時（ISO文字列）
}
```
