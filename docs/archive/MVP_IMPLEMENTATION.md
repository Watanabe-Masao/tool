## 🚀 使い方

### 1. 計算結果を保存

1. 通常通り計算を実行
2. 結果が表示されたら **「💾 この計算を保存」** ボタンをクリック
3. **カテゴリーを選択**（🥬 野菜 / 🍎 果実）
4. **商品名を入力**
   - カテゴリーに応じた既存商品名が候補として表示される
   - 既存の商品名から選択または新規入力
5. **「保存」** をクリック

### 2. 履歴から読み込み

1. **「📂 履歴」** ボタンをクリック
2. 保存済みの計算一覧が表示される
3. 同一商品名が複数ある場合:
   - 横スワイプ（タッチまたはマウスドラッグ）で切り替え
   - インジケーター（●●●）で現在位置を確認
   - 「○件の履歴」と表示
4. 読み込みたい計算の **「📂 読込」** ボタンをクリック
5. 入力値が自動で復元され、計算が実行される

### 3. 検索・管理

- **検索**: 上部の検索ボックスで商品名を絞り込み
- **編集**: 商品名・カテゴリを編集
- **削除**: 不要なデータを削除
- **エクスポート**: JSONファイルとしてバックアップ
- **インポート**: 別端末でJSONファイルを復元

### 4. PWAとしてインストール

#### スマホ（Android）
1. Chromeでアクセス
2. メニュー → **「ホーム画面に追加」**
3. アイコンがホーム画面に表示される

#### スマホ（iOS）
1. Safariでアクセス
2. 共有ボタン → **「ホーム画面に追加」**

#### PC
1. Chrome/Edgeでアクセス
2. アドレスバー右側の **インストールアイコン** をクリック

### 5. アプリ更新

**自動更新**:
- アプリは1時間ごとに新バージョンをチェック
- 新バージョンが利用可能な場合、画面上部に通知が表示される

**更新方法**:
```
🔄 新しいバージョンが利用可能です [更新] [✕]
```
1. **「更新」** ボタンをクリック
2. ページが自動的にリロードされ、新バージョンが適用される

**手動更新**:
- ハードリロード（Ctrl+Shift+R / Cmd+Shift+R）
