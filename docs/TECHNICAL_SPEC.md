# 技術仕様（数式・ロジック）

本書は、逆算シミュレーションと関連する主要な式を、非技術者にも読みやすい形で説明します。

---

## 1. 記号と意味
- **bp**：値引き前単価（円/個）
- **dc**：値引き額（円/個）
- **ap**：値引き後単価（= bp - dc, 円/個）
- **yr**：値引き後粗利率（%）
- **am**：加工後重量（g/個）
- **bm**：加工前重量（g/個）
- **bc**：重量単価ベースの原価（円/g）

---

## 2. 基本式
粗利率の定義：
```
粗利率 = (売価 - 原価) / 売価
```
値引き後の売価を `ap` とすると、**1 個あたり原価 `ac`** は：
```
ac = ap * (1 - yr/100)
```

### 例
`bp=200, dc=20 → ap=180, yr=35%`  
`ac = 180 * (1 - 0.35) = 117（円/個）`

---

## 3. 重量ベース原価との関係
重量ベースで原価を入れる場合、1 個あたりの原価は：
```
ac_weight = am * bc
```
この値を用いると、目標の粗利率は
```
yr = 1 - (ac / ap) = 1 - (am * bc) / ap
```

---

## 4. 目標値入率から必要重量を逆算
商品化時の重さ `w` と消耗品費 `consumable` を考慮した目標値入率 `targetMarkup`（%）から、**必要な重量**を求めます。

前提：
```
price = afterPrice * w / 100
cost  = afterCost  * w / 100 + consumable
markup = ((price - cost) / price) * 100
```
整理すると：
```
w = consumable * 100 / (afterPrice * (1 - targetMarkup/100) - afterCost)
```
※ 分母が 0 以下の場合は解なし（条件不成立）

---

## 5. 設計上の注意
- 入力値の **0/負値** は不正として扱い、計算を中断  
- 小数は丸めを適切に制御（画面表示は `toFixed`）  
- 関数は **副作用なし** に保ち、UI 層（DOM 操作）と分離
