### Bug 1: Null参照エラーの修正

#### 修正内容

Optional chaining (`?.`) の追加

```javascript
// Before (エラー発生)
const discountRate = parseFloat(qs(`#${UI_ELEMENTS.DISC_INPUT}`).value) || 0;

// After (修正後)
const discountRate = parseFloat(qs(`#${UI_ELEMENTS.DISC_INPUT}`)?.value) || 0;
```

#### 検証項目
- ✅ Test 1: 要素が存在する場合、正常に値を取得できる
- ✅ Test 2: 要素が存在しない場合、エラーが発生せずデフォルト値0を返す
- ✅ Test 3: Optional chainingなしではTypeErrorが発生する（修正前の動作確認）

---

### Bug 2: JSON.parseエラーハンドリング

#### 修正内容

try-catchブロックの追加と破損データの自動クリア

```javascript
// Before (エラー発生)
const parsedPresets = JSON.parse(presets);
return parsedPresets.map(preset => ({...}));

// After (修正後)
try {
  const parsedPresets = JSON.parse(presets);
  return parsedPresets.map(preset => ({...}));
} catch (error) {
  console.error('Failed to parse presets from localStorage:', error);
  localStorage.removeItem(PRESET_STORAGE_KEY);
  return [];
}
```

#### 検証項目
- ✅ Test 4: 正常なJSONデータを正しくパースできる
- ✅ Test 5: 破損したJSONデータでもエラーが発生せず空配列を返す
- ✅ Test 6: 破損したデータは自動的にクリアされる
- ✅ Test 7: patternsプロパティがない古いデータも処理できる

---

### Bug 3: 配列境界チェック

#### 修正内容

インデックスの範囲チェック追加

```javascript
// Before (境界チェックなし)
const sorted = [...tempPairs].sort((a, b) => b.unitPrice - a.unitPrice);
const pairToRemove = sorted[index]; // indexが範囲外の場合undefined

// After (修正後)
const sorted = [...tempPairs].sort((a, b) => b.unitPrice - a.unitPrice);

if (index < 0 || index >= sorted.length) {
  console.error('Invalid index:', index);
  return;
}

const pairToRemove = sorted[index];
```

#### 検証項目
- ✅ Test 8: 有効なインデックスで配列要素を削除できる
- ✅ Test 9: 負のインデックスではエラーが発生し、配列は変更されない
- ✅ Test 10: 範囲外のインデックスではエラーが発生し、配列は変更されない
- ✅ Test 11: 空配列に対するインデックス0でもエラーが発生する
- ✅ Test 12: 境界値（配列の長さ-1）で正常に削除できる

## 統計計算検証テスト

### 概要

### テストファイル: `test-statistics.js`

- **実行方法**: `node test-statistics.js`
- **テスト結果**: ✅ 18/18 成功 (100%)

### 修正内容

#### 変更点

**修正前（母標準偏差）:**
```javascript
const variance = values.reduce((sum, val) => sum + Math.pow(val - mean, 2), 0) / n;
```

**修正後（不偏標準偏差）:**
```javascript
const variance = n > 1
  ? values.reduce((sum, val) => sum + Math.pow(val - mean, 2), 0) / (n - 1)
  : 0;
```

#### なぜ不偏標準偏差が必要か

- **母標準偏差（/n）**: 母集団全体のデータがある場合に使用
- **不偏標準偏差（/(n-1)）**: サンプルデータから母集団を推定する場合に使用

歩留まり率の統計分析では、通常サンプルデータから母集団を推定するため、不偏標準偏差を使用するのが適切です。

### 手動計算例

データ: [10, 20, 30]

#### ステップ1: 平均を計算
```
平均 = (10 + 20 + 30) / 3 = 20
```

#### ステップ2: 偏差の2乗和を計算
```
(10 - 20)² = 100
(20 - 20)² = 0
(30 - 20)² = 100
合計 = 200
```

#### ステップ3: 不偏分散を計算
```
不偏分散 = 200 / (3 - 1) = 200 / 2 = 100
```

#### ステップ4: 不偏標準偏差を計算
```
不偏標準偏差 = √100 = 10
```

### 検証のポイント

#### ✅ 確認すべき点

1. **分母がn-1になっているか**
   - 母標準偏差（/n）ではなく、不偏標準偏差（/(n-1)）を使用

2. **n=1の場合の処理**
   - 0除算を避けるため、標準偏差を0とする

3. **歪度・尖度の条件**
   - 歪度: n >= 3の場合のみ計算
   - 尖度: n >= 4の場合のみ計算

#### ❌ よくある間違い

1. **母標準偏差を使用**: `/n` で割ってしまう
2. **n=1の処理漏れ**: 0除算エラーが発生
3. **条件の誤り**: `n > 2` と `n >= 3` は異なる

### アニメーションが表示されない

**原因**:
- ブラウザのハードウェアアクセラレーションが無効
- 古いブラウザを使用している

**解決方法**:
1. ブラウザのハードウェアアクセラレーションを有効にする
2. 別のブラウザ（Chrome/Firefox）で試す
3. ブラウザのキャッシュをクリア（Ctrl+Shift+R / Cmd+Shift+R）

---

### プログレスバーが表示されない

**原因**:
- 許容誤差（E）に値が入力されていない
- JavaScriptエラーが発生している

**解決方法**:
1. 許容誤差（E）に値が入力されているか確認
2. ブラウザのコンソールエラーを確認（F12）
3. ページをリロード（F5）

---

2. ページをリロード（F5）
3. キャッシュをクリアしてリロード（Ctrl+Shift+R）
