## 機能概要

Firebase同期機能により、以下が可能になります：

### ✅ できること

- **複数デバイス間でのデータ共有**: スマホ、タブレット、PC間で計算履歴を同期
- **匿名ログイン**: メールアドレス不要で即座に使用開始
- **メールアカウント**: メールアドレスで登録すれば、デバイス紛失時も安心
- **自動同期**: ログイン中は定期的に自動でデータを同期
- **オフライン対応**: ネット接続がなくても動作し、接続時に自動同期
- **競合解決**: 複数デバイスで変更した場合、最新のデータを優先

### 🔐 セキュリティ

- ユーザーは自分のデータのみアクセス可能
- パスワードは暗号化されて保存
- Firebase のセキュリティルールで保護

## Firebase プロジェクトの作成

### ステップ 1: Firebase コンソールにアクセス

1. [Firebase Console](https://console.firebase.google.com/) にアクセス
2. Google アカウントでログイン
3. 「プロジェクトを追加」をクリック

### ステップ 2: プロジェクト情報を入力

1. **プロジェクト名**: `yield-calculator`（任意の名前でOK）
2. **Google アナリティクス**: 不要なら「無効」を選択
3. 「プロジェクトを作成」をクリック

### ステップ 3: ウェブアプリを追加

1. プロジェクトのホーム画面で「ウェブ」アイコン（`</>`）をクリック
2. **アプリのニックネーム**: `yield-calculator-web`
3. **Firebase Hosting**: チェック不要
4. 「アプリを登録」をクリック
5. **表示された設定値をコピー**（後で使います）

```javascript
// このような設定値が表示されます
const firebaseConfig = {
  apiKey: "AIza....",
  authDomain: "your-project.firebaseapp.com",
  projectId: "your-project",
  storageBucket: "your-project.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abcdef"
};
```

## 認証設定

### ステップ 4: 認証方法を有効化

1. Firebase コンソールの左メニューから「Authentication」を選択
2. 「始める」をクリック
3. 「Sign-in method」タブを選択
4. 以下の2つの認証方法を有効化：

#### 4-1. 匿名認証を有効化

- 「匿名」をクリック
- 「有効にする」をON
- 「保存」をクリック

#### 4-2. メール/パスワード認証を有効化

- 「メール/パスワード」をクリック
- 「有効にする」をON
- 「保存」をクリック

## Firestore データベース設定

### ステップ 5: Firestore データベースを作成

1. Firebase コンソールの左メニューから「Firestore Database」を選択
2. 「データベースの作成」をクリック
3. **ロケーション**: `asia-northeast1`（東京）を選択
4. **セキュリティルール**: 「テストモードで開始」を選択
5. 「有効にする」をクリック

### ステップ 6: セキュリティルールを設定

データベース作成後、セキュリティルールを設定します：

1. 「ルール」タブを選択
2. 以下のルールをコピー＆ペースト：

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // ユーザーは自分のデータのみアクセス可能
    match /users/{userId}/history/{historyId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }

    // ユーザー設定
    match /users/{userId}/settings/sync {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
```

3. 「公開」をクリック

## アプリケーション設定

### ステップ 7: Firebase 設定をアプリに反映

1. プロジェクトの `scripts/firebase-config.js` ファイルを開く
2. ステップ3でコピーした設定値を貼り付ける：

```javascript
export const firebaseConfig = {
  apiKey: "YOUR_API_KEY",              // ← ここを変更
  authDomain: "YOUR_PROJECT_ID.firebaseapp.com",
  projectId: "YOUR_PROJECT_ID",
  storageBucket: "YOUR_PROJECT_ID.appspot.com",
  messagingSenderId: "YOUR_MESSAGING_SENDER_ID",
  appId: "YOUR_APP_ID"
};
```

3. Firebase 機能を有効化：

```javascript
export const firebaseFeatures = {
  enabled: true,        // ← false から true に変更
  autoSync: true,       // 自動同期を有効にする
  syncInterval: 300000, // 5分ごとに同期（ミリ秒）
};
```

4. ファイルを保存

### ステップ 8: アプリを起動

```bash
# 開発サーバーを起動（もしあれば）
npm start

# またはシンプルにHTMLファイルを開く
open index.html
```

## 使い方

### 初回ログイン

1. アプリを開くと、ヘッダーに「☁️ 未ログイン」と表示される
2. 「ログイン」ボタンをクリック
3. ログイン方法を選択：

#### パターンA: 匿名ログイン（推奨）

- 「匿名でログイン」ボタンをクリック
- 即座に使用開始可能
- 後でメールアドレスを登録してアップグレード可能

#### パターンB: メールでアカウント作成

- 「アカウント作成」リンクをクリック
- メールアドレスとパスワード（6文字以上）を入力
- 「アカウント作成」ボタンをクリック

### データを同期する

#### 手動同期

1. 「🔄 同期」ボタンをクリック
2. ローカルデータをクラウドにアップロード
3. クラウドからデータをダウンロード
4. トースト通知で結果を確認

#### 自動同期

- ログイン中は5分ごとに自動で同期
- バックグラウンドで動作するため、操作不要

### 別のデバイスで使う

1. 新しいデバイスでアプリを開く
2. 同じアカウントでログイン
   - 匿名ユーザー: **デバイスごとに異なるため不可** → メールアカウントにアップグレード推奨
   - メールアカウント: 同じメールとパスワードでログイン
3. 「🔄 同期」ボタンをクリック
4. データがダウンロードされる

### 匿名アカウントをアップグレード

匿名でログインした後、メールアカウントに変更する方法：

1. ログイン中に「ログアウト」→「ログイン」をクリック
2. アップグレード画面が表示される
3. メールアドレスとパスワードを入力
4. 「アカウントをアップグレード」ボタンをクリック
5. これで別のデバイスからもアクセス可能に！

## トラブルシューティング

### Q1. 「Firebase初期化に失敗しました」と表示される

**原因**: 設定値が間違っているか、Firebase SDKが読み込まれていない

**解決策**:
1. `scripts/firebase-config.js` の設定値を確認
2. ブラウザの開発者ツール（F12）でエラーを確認
3. `firebaseFeatures.enabled` が `true` になっているか確認

### Q2. 「ログインに失敗」と表示される

**原因**: 認証設定が有効になっていない

**解決策**:
1. Firebase コンソールの「Authentication」→「Sign-in method」を確認
2. 「匿名」と「メール/パスワード」が有効になっているか確認

### Q3. 「同期に失敗」と表示される

**原因**: Firestoreのセキュリティルールが正しくない、またはネット接続がない

**解決策**:
1. ネット接続を確認
2. Firebase コンソールの「Firestore Database」→「ルール」を確認
3. セキュリティルールが正しく設定されているか確認

### Q4. データが同期されない

**原因**: 匿名アカウントでは、デバイスごとに異なるアカウントになる

**解決策**:
- 匿名アカウントをメールアカウントにアップグレード
- または最初からメールアカウントで登録

### Q5. 複数デバイスで異なるデータが表示される

**原因**: 競合が発生している

**解決策**:
- 各デバイスで「🔄 同期」ボタンをクリック
- 最新のタイムスタンプのデータが優先される

### Q6. Firebase機能を無効にしたい

**解決策**:
1. `scripts/firebase-config.js` を開く
2. `firebaseFeatures.enabled` を `false` に変更
3. アプリを再読み込み
4. クラウド同期のUIが非表示になる

## 料金について

### Firebase 無料枠（Spark プラン）

Firebase は無料で使用開始でき、以下の無料枠があります：

| サービス | 無料枠 |
|---------|--------|
| **認証** | 無制限 |
| **Firestore 読み取り** | 50,000回/日 |
| **Firestore 書き込み** | 20,000回/日 |
| **Firestore ストレージ** | 1 GB |

### 想定使用量

このアプリの場合：

- **1回の同期**: 読み取り 約50回、書き込み 約50回
- **1日10回同期** × **10ユーザー**: 読み取り 5,000回、書き込み 5,000回
- **無料枠内で十分使用可能** 🎉

無料枠を超える場合のみ、従量課金（Blaze プラン）への切り替えが必要です。

## セキュリティのベストプラクティス

### 1. API Key の管理

- `firebase-config.js` をGitにコミットする場合、プライベートリポジトリを推奨
- パブリックリポジトリの場合、環境変数化を検討

### 2. セキュリティルールの定期確認

- Firebase コンソールで定期的にルールを確認
- ユーザーが自分のデータのみアクセスできることを確認

### 3. パスワードのベストプラクティス

- 6文字以上（Firebaseの制限）
- 英数字と記号の組み合わせを推奨
- 使い回しを避ける
