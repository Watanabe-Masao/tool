## 🛠️ 開発環境のセットアップ

```bash
# リポジトリのクローン
git clone https://github.com/Watanabe-Masao/tool.git
cd tool

# 依存関係のインストール
npm install

# テストの実行
npm test

# ローカルサーバーの起動
npx http-server -p 8080
```
